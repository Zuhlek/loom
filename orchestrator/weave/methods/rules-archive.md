# Rules archive

Retired rules and rejected proposals of the **overall** store (`methods/principles.md ## Learned rules`) — nothing else. Two writers: humans move retired entries here from that store; the orchestrator appends proposals rejected at the review gate. Append-only. Never loaded into any prompt — only the Review phase reads it before proposing, so retired or rejected entries are not re-proposed.

Repo-scoped rules never appear here. Each repo store (`~/.claude/loom/rules/<slug>.md`) carries its own `## Archive` section, so nothing about a work repo is tracked in the loom repo.
